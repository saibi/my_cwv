# 계획 인덱스

계획마다 영문 대문자 3자 ID를 붙인다. 하위 항목은 `<ID>-Q1`(결정 사항), `<ID>-M1`(마일스톤), `<ID>-R1`(리뷰 지적사항)으로 부른다.

| ID | 계획 | 상태 |
| :--- | :--- | :--- |
| CWV | 커뮤니티 웹 모아보기 iOS 앱 | 구현 완료 (실기기 설치됨, 동작 확인과 SideStore 설정은 보류) |
| UXP | 사용성 개선: 앱 아이콘, 플로팅 버튼 통일/이동, 광고 숨기기 | 구현 완료 (드래그 동작은 실기기 확인 필요) |
| PRS | 플로팅 버튼 튕기기/Safari 열기, 기본 페이지 CSV, 사용자 페이지 재설치 후 유지 | 구현 완료 (실기기 확인 필요) |
| SWT | 첫 페이지에서 스와이프로 목록 복귀, 목록 제목을 페이지 타이틀로 | 구현 완료 (스와이프는 실기기 확인 필요) |
| LST | 사이트 목록 통합, 기본값 초기화, CSV 백업/복원 | 구현 완료 (편집/파일 앱은 실기기 확인 필요) |
| OPT | 옵션(기본 확대%), CSV 형식 url,name,%, 사이트 편집 보완 | 구현 완료 (편집/옵션은 실기기 확인 필요) |
| IPD | 아이패드 지원 (기기 패밀리, 방향, 사이트별 데스크톱 레이아웃, CSV v3, 목록 폭) | 구현 완료 (iPad 실기기 확인 필요) |
| SPL | iPad 분할 화면 (목록 + 웹, 목록 좌/우, 너비 조절, 레이아웃 CSV 백업) | 구현 완료 (iPad 실기기 확인 필요) |
| VER | 앱 버전 관리(0.1.0 시작, 증가 규칙)와 목록 화면 버전/빌드 시각 표시 | 구현 완료 (버전 탭 말풍선은 실기기 확인 필요) |
| SWB | 버전 표시 색 개선, 분할 화면 페이지 영역 뒤로/앞으로가기 스와이프 | 구현 완료 (스와이프는 iPad 실기기 확인 필요) |
| JOY | 플로팅 버튼 조이스틱 조작 (뒤로/앞으로, 글자 크기, 모서리 이동) | 구현 완료 (끌기 동작은 실기기 확인 필요) |
| SNS | 조이스틱 감도 설정 (옵션 슬라이더, 기기별 저장) | 계획 확정 (구현 전) |
