# CWV - 커뮤니티 웹 모아보기

자주 가는 커뮤니티 사이트를 앱 하나에 모아 보고, 사이트별 글자 크기를 조절해 기억하는 개인용 iOS 앱입니다 (SwiftUI + WKWebView).

## 사용
- 목록: 하나의 목록입니다. `+`로 추가하고, 행을 왼쪽으로 밀면 편집/삭제, `편집` 버튼으로 모든 항목의 순서 변경과 삭제를 합니다 (전부 지워도 됩니다). 이름을 비우면 사이트를 처음 열었을 때 받은 페이지 제목을 씁니다. `편집` 버튼을 누른 상태에서 행을 탭하거나, 행을 길게 누르거나 밀면 이름/주소/확대%를 편집할 수 있습니다.
- iPhone과 iPad를 모두 지원합니다 (iPad는 모든 방향과 멀티태스킹을 지원합니다). 사이트마다 "데스크톱 사이트로 보기"를 편집 화면이나 웹 화면의 플로팅 메뉴에서 켜고 끌 수 있습니다 (기본은 모바일, 바꾸면 바로 다시 불러옵니다).
- 상단 `...` > 옵션: 기본 확대%(처음 120%). 새로 추가하는 사이트와 확대%가 없는 CSV 줄에 적용되고, 이미 있는 사이트는 바뀌지 않습니다.
- iPad의 넓은 화면(전체 화면, 절반 이상의 분할 창)에서는 목록과 사이트를 한 화면에 같이 보입니다. 목록에서 다른 사이트를 누르면 웹 영역만 바뀌고, 목록과 웹 사이의 경계를 끌어서 목록 너비를 바꿉니다 (240~480pt, 기본 320pt). 목록 위치(왼쪽/오른쪽)는 `...` > 옵션 > "iPad 분할 화면"에서 고릅니다. 목록은 목록 위쪽 버튼이나 웹 화면 플로팅 메뉴의 "목록 숨기기/보이기"로 접고 폅니다. Slide Over 같은 좁은 창과 iPhone은 지금처럼 목록과 웹을 오갑니다. 분할 화면에서는 페이지 영역의 가장자리 24pt에서 시작한 스와이프로 뒤로(왼쪽 가장자리에서 오른쪽으로)/앞으로(오른쪽 가장자리에서 왼쪽으로) 갑니다. 웹이 화면 끝에 닿은 쪽은 기본 제스처가 처리합니다.
- 첫 실행 때만 `default_page.csv`(아래)로 목록을 만들고, 그 뒤로는 앱이 목록을 바꾸지 않습니다. 상단 `...` 메뉴에서 기본값으로 초기화(앱에 들어 있는 기본 목록으로 교체), CSV로 백업(파일 앱/iCloud Drive에 저장), CSV에서 복원(현재 목록을 파일 내용으로 교체)을 할 수 있습니다. 백업 CSV(v3)는 첫 줄이 `# v3`, 이어서 `# device: ipad|iphone`(만든 기기), iPad에서 만든 파일은 `# sidebar-side/width/hidden:`(분할 화면의 목록 위치/너비/숨김, iPad에서 복원할 때만 적용), 한 줄에 `주소,"이름",확대%,m|d`(m 모바일, d 데스크톱)입니다. 다른 기기에서 만든 파일을 복원할 때는 "그대로 복원"과 "데스크톱 설정은 빼고 복원" 중에서 고를 수 있습니다 (v2 이하 파일은 모두 모바일) (`default_page.csv`와 같은 형식). 첫 줄이 이 주석이 아닌 파일은 v1(`주소[,이름]`, 확대% 없음)로 읽습니다. 이름이 비어 있던 사이트는 저장된 페이지 제목이 이름으로 적히며 (복원하면 접속 없이 바로 보임, 이후 고정),  복원은 1MB, 500개까지이고 (넘는 목록은 백업 단계에서 막습니다), 같은 주소도 이름이 다르면 모두 보존합니다.
- 목록과 사이트별 글자 크기는 Keychain에도 백업되어, 앱을 지우고 다시 설치해도 같은 서명(Team ID/번들 ID)이면 복원됩니다. 버튼 위치와 마지막으로 연 사이트는 복원되지 않습니다.
- 웹뷰: 말풍선 모양 플로팅 버튼(기본 오른쪽 아래)에서 글자 크기(50~300%), `Safari에서 열기`(지금 보는 페이지), `목록으로`. 버튼을 끌거나 튕기면 그 방향 모서리로 붙고 위치는 저장됩니다. 가장자리 스와이프로 뒤로/앞으로(사이트의 첫 페이지에서는 왼쪽 가장자리 스와이프가 목록으로 돌아감), 당겨서 새로고침.
- 다른 도메인 링크는 앱 안의 Safari 시트로 열립니다 (시트 하단 "Safari에서 열기"로 Safari 앱 이동 가능).
- 광고(Google 광고, 카카오 애드핏)는 `cwv/CWV/adblock.json` 규칙으로 차단/숨깁니다. 사이트가 늘면 이 파일에 도메인이나 선택자를 추가하세요.
- Google 소셜 로그인은 내장 웹뷰에서 Google이 차단합니다.

## 기본 페이지 파일 (빌드 전 필수)
앱 첫 실행과 "기본값으로 초기화"에 쓰는 기본 목록은 `cwv/CWV/default_page.csv`입니다. 개인 목록이라 git에 올리지 않으므로 **빌드 전에 직접 만들어야 합니다**. 없으면 빌드 때 경고가 나오고 기본 목록은 Google 하나가 됩니다. 앱에 이미 목록이 저장되어 있으면 이 파일을 고쳐 다시 설치해도 목록은 바뀌지 않습니다 (바꾸려면 앱에서 초기화).
```
cp cwv/default_page.csv.example cwv/CWV/default_page.csv   # 견본을 복사해 고친다
```
- 첫 줄이 `# v2` 또는 `# v3`이면 한 줄에 사이트 하나 `주소,"제목",확대%[,m|d]`(`d` 데스크톱 사이트는 v3만). 예: `https://damoang.net/empathy,"다모앙-공감",120` (제목은 항상 큰따옴표로 감싸고 안의 `"` `\`는 `\"` `\\`로 씁니다. 확대%는 `120` 또는 `120%`, 없으면 옵션의 기본 확대%). 첫 줄이 이 주석이 아니면 v1: `주소[,제목]`, 첫 쉼표 뒤가 모두 제목이고 확대%는 없습니다.
- 제목은 옵션입니다. 없으면 사이트를 처음 열었을 때 받은 페이지 제목이 목록 이름이 되고(그 전에는 도메인), 한 번 받은 제목은 앱을 다시 실행해도 유지됩니다. 주소에 쉼표가 있으면 주소를 따옴표로 감쌉니다 (예: `"https://a.com/?q=a,b","이름",100`, 주소 안의 따옴표는 두 개).
- `#`으로 시작하는 줄, 빈 줄, 잘못된 주소 줄은 무시합니다. 앱에서 백업한 CSV를 이 파일로 복사해 기본값으로 쓸 수도 있습니다.

## 개발
- 앱 아이콘 재생성: `swiftc -parse-as-library cwv/CWV/AppGlyph.swift cwv/make_icon.swift -o build/make_icon && build/make_icon out.png && cp out.png cwv/CWV/Assets.xcassets/AppIcon.appiconset/icon.png` (버튼과 같은 `AppGlyph`로 그림)
- 버전: `cwv/Version.xcconfig`의 `MARKETING_VERSION` 한 줄만 고친다 (올리는 규칙은 `AGENTS.md` "버전 관리"). 목록 화면 제목 옆의 `v0.1.0`을 탭하면 빌드 시각이 보인다 (빌드 때마다 `BuildTime.txt`로 갱신).
- 자체 검증: `swiftc -parse-as-library cwv/CWV/Site.swift cwv/CWV/SiteStore.swift cwv/test_site.swift -o build/test_site && build/test_site`
- 실기기 확인: Xcode에서 `cwv/CWV.xcodeproj`를 열고 Signing에 본인 Apple ID 팀을 지정한 뒤 Run.

## 7일마다 재설치
(iPad도 같은 방법입니다: `sh cwv/reinstall.sh <iPad의 UDID>`. 처음이면 iPad의 설정 > 개인정보 보호 및 보안 > 개발자 모드를 켜야 합니다.)
무료 Apple ID로 설치한 앱은 7일 뒤에 만료됩니다. 만료 전에 아이폰을 USB로 연결하고 잠금을 푼 뒤 실행합니다.
```
sh cwv/reinstall.sh
```
- 연결된 아이폰을 자동으로 찾아 빌드하고 덮어쓰기 설치합니다. 사이트 목록과 설정은 유지됩니다. 기기가 여러 대면 `sh cwv/reinstall.sh <UDID>`.
- Xcode Signing에서 Team을 한 번 지정해 두어야 합니다 (그 설정은 `project.pbxproj`에 들어가지만 커밋하지 않습니다).
- 처음 설치한 기기는 설정 > 일반 > VPN 및 기기 관리에서 개발자 프로필을 신뢰해야 실행됩니다.
- 빌드 중 서명 단계에서 맥이 키체인 접근 허용을 물으면 허용해야 진행됩니다 (화면이 잠겨 있으면 멈춥니다).

### SideStore는 쓰지 않습니다
SideStore(7일 자동 갱신)를 시도했지만 이 프로젝트에서는 설정 중 `Bundle identifier unavailable` 오류로 설치가 막혀 접었습니다 (원인은 확인하지 못했습니다). 맥을 일주일에 한 번 이상 쓴다면 위 방식이 더 간단합니다. `cwv/make_ipa.sh`(무서명 IPA)는 다른 도구로 설치할 때를 위해 남겨 둡니다.
