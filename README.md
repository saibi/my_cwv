# my_cwv - 커뮤니티 웹 모아보기

자주 가는 커뮤니티 사이트를 앱 하나에 모아 보고, 사이트별로 글자 크기를 조절해 기억하는 개인용 iOS 앱입니다 (SwiftUI + WKWebView).

Safari "홈 화면에 추가" 웹 앱에는 글자 크기 조절이 없고, 사이트가 iframe과 프록시를 막아 감쌀 수도 없어서 만들었습니다.

- 앱 코드와 사용법: [cwv/README.md](cwv/README.md)
- 계획/구현/리뷰 기록: `plan/`, `impl/`, `review/`
- 에이전트(Claude Code 등) 작업 규칙: [AGENTS.md](AGENTS.md)
