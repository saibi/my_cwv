# [SWT] 교차리뷰 (codex-gpt-6.1-sol)

## 요약

계획의 주요 코드와 콜백 연결은 구현되어 있습니다. 다만 주소 변경 시 제목 캐시가 잘못 유지되며, 명시적 CSV 제목에도 이전 데이터 호환 규칙이 적용됩니다. 두 문제를 수정하고 SWT-M2/M3의 남은 검증을 마쳐야 합니다.

| 계획 항목 | 구현 상태 | 검증 판단 |
| --- | --- | --- |
| SWT-M1 표시 이름/CSV/제목 저장 | 구현 | 주요 순수 함수와 저장 테스트가 있습니다. 주소 변경과 명시적 도메인 제목 사례는 빠졌습니다. |
| SWT-M2 첫 페이지 제목 수집 | 구현/검증 일부 | 구현 노트에 수집과 재실행 확인이 있습니다. 상세 제목 제외는 미확인입니다. |
| SWT-M3 가장자리 스와이프 | 구현/검증 미완료 | 임계값 테스트만 있습니다. 실기기 제스처와 웹 뒤로가기 우선 동작은 미확인입니다. |
| SWT-Q1 한 번 스와이프로 목록 복귀 | 코드 반영 | 실기기 확인이 필요합니다. |
| SWT-Q2 사이트를 열면 제목 수집 | 반영 | 전체 사이트를 미리 요청하지 않습니다. |
| SWT-Q3 제목은 UserDefaults에만 저장 | 반영 | Keychain 백업 데이터에서 제외되어 있습니다. |

계획에 추가된 Cloudflare 확인 화면 제목 제외는 잘못된 제목의 영구 저장을 막으려는 타당한 보완입니다. 다음 런루프로 제목 콜백을 미루는 이유도 타당합니다.

변경 코드에는 다운로드 파일 처리나 subprocess/외부 CLI 호출이 없습니다. 외부 제목은 문자열로 저장하고 `Text`로 표시하며 코드로 실행하지 않습니다.

## 지적사항

### SWT-R1 주소 변경 후에도 이전 사이트 제목이 표시됩니다

- **분류**: 확실한 문제
- **심각도**: 중간
- **위치**: `cwv/CWV/SiteStore.swift:91`
- **내용**: 주소가 바뀌면 웹뷰만 삭제하고 같은 ID의 `pageTitles`는 유지합니다. 자동 이름 사이트 `https://a.com`에서 제목을 받은 뒤 주소를 `https://b.com`으로 편집하면, 목록에는 계속 A의 제목이 표시됩니다. B를 열지 않거나 네트워크 실패로 제목을 받지 못하면 재실행 후에도 잘못된 이름이 남습니다.
- **제안**: 주소 변경 분기에서 해당 ID의 제목 캐시도 삭제하십시오. 제목 저장 후 주소를 변경했을 때 새 도메인이 표시되고, 재생성한 스토어에서도 유지되는 테스트를 추가하십시오.

### SWT-R2 상세 제목 제외와 실제 제스처의 완료 기준을 검증하지 못합니다

- **분류**: 확실한 문제
- **심각도**: 중간
- **위치**: `cwv/test_site.swift:147`, `impl/SWT_impl_claude-sonnet-5-5.md:37`
- **내용**: 제목 테스트는 `setPageTitle`을 직접 호출하므로 실제 KVO 수집과 웹 기록 판정을 거치지 않습니다. `WebView.swift`는 자체 검증의 컴파일 대상에도 없습니다. 따라서 상세 페이지의 일반 제목까지 저장하도록 회귀해도 테스트가 통과합니다. 스와이프 테스트도 숫자 판정만 확인하므로, 제스처가 시작되지 않거나 웹 뒤로가기와 충돌해도 통과합니다. 구현 노트 역시 해당 시나리오를 미확인으로 명시합니다.
- **제안**: 로컬 HTML 첫 페이지와 상세 페이지로 제목 수집/상세 제목 제외/뒤로 복귀를 검증하십시오. SWT-M3는 계획대로 실기기에서 첫 페이지 목록 복귀와 상세 페이지 웹 뒤로가기를 각각 확인하고 결과를 기록하십시오. 그전까지 M2/M3의 검증 상태를 미완료로 유지하십시오.

### SWT-R3 명시한 CSV 제목이 도메인과 같으면 무시됩니다

- **분류**: 확실한 문제
- **심각도**: 낮음
- **위치**: `cwv/CWV/Site.swift:17`
- **내용**: `displayName`은 출처와 관계없이 이름이 도메인과 같으면 자동 이름으로 처리합니다. CSV에 `https://a.com,a.com`을 명시해도 페이지 제목을 수집한 뒤에는 그 제목으로 바뀝니다. 계획에서 도메인 이름을 자동으로 간주하는 대상은 이미 저장된 사용자 사이트이며, 명시적 CSV 제목은 우선해야 합니다.
- **제안**: 기존 사용자 사이트의 도메인 이름을 로드 시 빈 이름으로 변환하고, 표시 함수에서는 비어 있지 않은 이름을 우선하십시오. CSV에 명시한 도메인 제목이 캐시보다 우선하는 테스트를 추가하십시오.

파일은 수정하지 않았습니다. 읽기 전용 환경이므로 빌드와 UserDefaults를 쓰는 자체 검증은 실행하지 않았습니다.
실기기 제스처, SPA 기록, 리다이렉트와 KVO 시점, 전환 애니메이션은 확인하지 못했습니다. 특히 SWT-M3의 핵심 사용자 동작은 검증이 남아 있습니다.
